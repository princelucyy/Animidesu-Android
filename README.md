# Animidesu

Animidesu adalah aplikasi anime lintas platform yang sedang dikembangkan.

## Tahap 1

- Flutter
- Android APK
- Material 3
- Home
- Koleksi
- Jadwal
- Profil

Tahap berikutnya akan menambahkan katalog anime, pencarian, detail anime, histori, favorit, jadwal real-time, player dan backend.
